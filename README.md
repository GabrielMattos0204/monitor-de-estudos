📚 Monitor de Estudos
Um aplicativo web simples e funcional desenvolvido com HTML, CSS e JavaScript puro para auxiliar no gerenciamento do tempo de estudo e consolidar meus conhecimentos fundamentais de desenvolvimento Front-end.

O projeto foi pensado para solucionar uma necessidade real da minha rotina de estudos, dividindo a sessão em blocos de tempo focados e mantendo o ritmo sem quebrar a sequência diária.

🚀 Funcionalidades
[x] Modos de Estudo: Suporte a sessões de 2h30 (Modo Completo) e 1h30 (Modo Curto).

[x] Cronômetro Regressivo: Contagem de tempo para cada bloco de estudo.

[x] Troca Automática de Blocos: Transição automática com alerta sonoro ao final de cada etapa.

[x] Controle de Fluxo: Opções para pausar, continuar ou pular o bloco atual.

[x] Design Responsivo: Interface escura (Dark Mode) otimizada para uso em telas de computador ou smartphones.

🧠 Conceitos Aplicados (Front-end)
Neste projeto, apliquei e estruturei de forma prática os seguintes conceitos:

HTML5: Estruturação semântica da interface e organização em componentes (div, button).

CSS3: Estilização moderna utilizando variáveis, Flexbox, layout responsivo e visual Dark Theme.

JavaScript (Vanilla):

Manipulação do DOM para atualização dinâmica do cronômetro e nomes dos blocos.

Uso de temporizadores (setInterval e clearInterval).

Lógica de estados para alterar os tempos de acordo com a meta escolhida (1h30 ou 2h30).

Web Audio API para emissão do sinal sonoro ao fim de cada ciclo.
